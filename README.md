# 📚 Chapterly

**Chapterly** is a simple **book tracking web application** built as a learning project.  
It allows users to track their reading progress, search the added books, manage book details, and organize their personal library efficiently.

---

## 🚀 Features

- ➕ **Add Books** with title, author, and progress  
- ✏️ **Edit or update book details**  
- 🗑️ **Delete books** from the list  
- 📖 **Track reading progress** and categorize books  
- 🔍 **Search Added Books** with title, author and category  
- 💾 Data stored using **JSON Server**  
- ⚡ Built with **React** for frontend and **Redux** for state management  

---

## 🧠 Tech Stack

- **Frontend:** React  
- **Backend:** JSON Server  
- **State Management:** Redux  
- **Styling:** CSS / Tailwind  

---

## 🎯 Purpose

This project was developed to **practice UI design principles** and strengthen understanding of **Redux** for state management.  
It helped in learning how to structure clean, interactive UIs while maintaining predictable app state using Redux.
